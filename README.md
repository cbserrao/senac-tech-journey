# Senac Tech Journey — protótipo 0.1
Projeto original em Three.js, sem Unity. Fachada ilustrativa, recepção preliminar, câmera de terceira pessoa, personagem articulado, colisões, teclado e controles de toque. A matrícula e as aulas ainda não foram implementadas.

## Teste local
Execute `python -m http.server 8000` nesta pasta e abra http://localhost:8000. A biblioteca Three.js é carregada pela internet.

## GitHub
Crie um repositório público `senac-tech-journey` e envie os arquivos. Ative Settings > Pages > Deploy from a branch > main > / (root). Teste primeiro o endereço GitHub Pages.

## Canva
Use o arquivo carregador-canva.js como referência para a integração. Substitua SEU_USUARIO pelo seu nome de usuário. Solicite ao Canva Code que crie uma experiência que carregue Three.js e simulador.js por scripts externos, se o sandbox permitir. O carregador precisa ser executado como JavaScript, não exibido como texto. A compatibilidade ainda não foi testada; se o Canva bloquear scripts externos, use um link para GitHub Pages.
