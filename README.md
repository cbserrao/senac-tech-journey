# Senac Tech Journey — v0.2
Protótipo educacional original em Three.js. Fachada inspirada na foto do Senac RR, sem pretensão de reprodução arquitetônica exata. Envie os cinco arquivos à raiz do repositório. GitHub Pages: main / root. Controles WASD/setas e E; botões de toque. Matrícula apenas simulada, sem envio ou armazenamento persistente de dados pessoais. A sala de aula ainda não está implementada. O carregador Canva usa jsDelivr e depende da permissão de scripts externos; integração ainda não testada. A geometria é procedural, sem modelos GLB nesta versão.
